# Blogs App

A blog-sharing app built with Next.js, Auth.js, Drizzle ORM, and Neon PostgreSQL.

Share blogs, like posts, and manage a reading list with read/unread status. Your profile also includes an API token for accessing your user details.

Run locally with `npm run dev` after installing dependencies and configuring database and auth environment variables in `.env.local`.
